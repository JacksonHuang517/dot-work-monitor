# Changelog

## 0.1.0

Initial public reference release: Feishu messages, owned tasks and calendar
polling; optional NetEase IMAP header monitoring; owner-bound OAuth, separate
source scopes, encrypted state and signed MCP Events; reproducible setup,
Docker deployment and automated tests.

Each deployment still requires its own provider authorization and a real Dot
subscription/delivery acceptance test. Account availability and external
platform behavior are outside the repository's control.
